JJ PLAYZ — GitHub Pages starter

FILES
- index.html: page structure
- style.css: responsive neon purple/cyan design
- script.js: mobile menu, theme switcher, current year
- launch.yml: GitHub Pages deployment workflow

PUBLISH
1. Create/open your GitHub repository.
2. Upload index.html, style.css and script.js to the repository root.
3. Put launch.yml inside .github/workflows/ (create those folders).
4. Open repository Settings > Pages.
5. Under Build and deployment, choose GitHub Actions.
6. Push to the main branch. The workflow deploys the site.

CUSTOMIZE
Search in index.html for JJ PLAYZ, the intro text, and social links to change them.
GitHub Pages serves static files, so Python cannot run on the Pages server. This site uses JavaScript for its interactive features.
